# PiWork 首页像素级复刻修订设计

## 背景

当前首页虽然实现了目标截图中的部分模块，但整体比例、信息密度、首屏内容、右侧活动栏和视觉层级偏离明显。用户要求以目标截图为唯一基准进行 1:1 复刻，并明确要求包含中部 3D 发光球插画。

本次修订覆盖此前首页仪表盘设计中“不精确复刻 3D 素材”的约束。验收以目标截图的 1536 × 1024 视口为主，现有业务能力继续工作。

## 选定方案

采用像素基准重构：以目标截图建立固定参考网格，重新排列真实 React 组件；从用户提供的目标截图提取 3D 发光球区域并进行边缘渐隐和背景融合；在小窗口中逐级收缩或隐藏次要区域。

不采用整图背景加交互热区，因为该方式会破坏可访问性、响应式布局和真实内容更新。也不重新生成 3D 插画，因为生成结果无法满足 1:1 视觉要求。

## 页面网格

1536 × 1024 主验收视口采用以下比例：

- 左侧全局侧栏约占 16%，固定在视口内。
- 首页主体约占 62%，包含首屏、任务卡、信息面板和 Composer。
- 右侧活动栏约占 19%，其余宽度用于栏间距与外边距。

页面高度限制在单个桌面视口内。首页主体内部允许在极小高度下滚动，但 1536 × 1024 下不得出现目标截图之外的纵向偏移或首屏裁切。

## 视觉设计

### 整体语言

- 使用目标截图中的冷白到浅蓝背景，主区域与侧栏之间以浅蓝描边区分。
- 卡片采用半透明白色表面、12–16px 圆角、浅蓝边框和低对比度蓝灰阴影。
- 品牌蓝只用于选中导航、主按钮、关键图标、状态强调和摘要图表。
- 标题、正文、辅助信息恢复目标截图的紧凑字号与行高，避免当前版本的大字号与过宽留白。

### 3D 发光球

- 从目标截图裁取中部发光球、轨道和周边悬浮元素，保存为首页专属图像资源。
- 通过渐变蒙版或透明边缘处理消除矩形裁切感，使素材与问候区背景自然融合。
- 素材使用等比例缩放和固定视觉锚点，1536 × 1024 下位置、大小与目标截图一致。
- 小窗口下优先缩小素材；当问候语可读性受到影响时隐藏最外层装饰，不移动标题层级。

## 组件结构

- `WorkSidebar`：品牌、新对话、主导航、项目树和底部账户，保持全高固定。
- `WorkHome`：首页网格容器，组合主体和右侧活动栏。
- `DashboardHeader`：左侧品牌/身份标识，右侧导入项目、探索智能体和通知。
- `DashboardGreeting`：问候文案、标题、副标题与 3D 发光球素材。
- 任务卡区域：五张等宽卡片，保持目标截图的图标颜色、标题、描述和右下角箭头。
- `RecentProjectsPanel`、`AgentSkillsPanel`、`EnvironmentStatusPanel`：同一行三列，固定相对宽度和统一高度。
- `AgentActivityPanel`、`DailySummaryPanel`：右栏上下排列，宽度与目标截图一致。
- Dashboard Composer：固定在主体底部，包含项目、运行环境、模型、附件能力和发送按钮。

所有区域使用真实 DOM，不以整张截图替代页面。

## 数据与交互

- 最近项目、项目树、环境检测和 Composer 继续使用现有真实数据与逻辑。
- 导入项目和新建对话继续执行现有回调。
- 智能体中心、知识库、数据源、探索智能体、活动筛选等尚未实现的能力保持可识别的禁用态。
- 单个面板的数据为空或请求失败时，只显示该面板空态，不改变其他面板的尺寸和位置。
- 交互状态只使用轻微的颜色、描边和阴影变化，不添加与目标截图不一致的大幅位移动画。

## 响应式规则

- 1536 × 1024：严格执行目标网格和像素对齐。
- 中等宽度：压缩间距、字号和卡片内边距，保持三栏结构。
- 右侧活动栏无法维持最小宽度时隐藏右栏，主体占据释放空间。
- 更窄窗口下将主体的三列信息面板改为两列或单列，并允许主体内部滚动。
- 左侧栏保持可用，不因响应式调整遮挡主内容。

## 可访问性与错误处理

- 按钮、导航、列表和表单保留正确语义与键盘焦点。
- 禁用功能使用原生 `disabled` 或 `aria-disabled`，不创建无反馈的可点击元素。
- 状态不仅依赖颜色，还保留文字与图标。
- 图像素材提供空替代文本，因为其为装饰内容；问候信息始终由真实文本表达。
- 环境检测失败时显示未知状态，不阻断首页渲染。

## 验收与验证

- 在 1536 × 1024 下截取应用首页，与目标截图并排核对三栏宽度、模块位置、卡片尺寸、间距、字体和颜色。
- 重点核对首屏未被裁切、3D 发光球位置、五张任务卡、三列信息面板、右侧活动栏和底部 Composer。
- 在较小窗口验证右栏隐藏和信息面板换列，不出现横向滚动、重叠或不可达控件。
- 运行首页、侧栏和 Composer 相关测试，并运行 `pnpm typecheck`、`pnpm test` 和 `pnpm build`。
- 视觉验收不以“风格相似”为通过标准；主验收视口必须与目标截图在结构和比例上明显一致。
